# Les sons de l'application : musiques, cloches, bruits, poèmes dits.
#
#     python build/sonoriser.py      télécharge, vérifie la licence, coupe l'extrait
#                                    dans son/ et écrit build/sons.json
#     node build/construire.mjs      rattache ensuite chaque son à ses articles
#
# Tous viennent de Wikimedia Commons et sont dans le domaine public (ou sous
# CC0) : le script refuse toute autre licence. Les enregistrements anciens le
# sont par leur âge, ceux des orchestres de l'armée américaine parce qu'ils sont
# l'œuvre d'un service fédéral, ceux de LibriVox et de Musopen par la volonté de
# leurs auteurs. On n'écoute un son qu'en le touchant : rien ne joue tout seul.
#
# ── Un son ──────────────────────────────────────────────────────────────────
#
#   = dies-irae                   identifiant : le fichier sera son/dies-irae.mp3
#   commons: Dies.irae.ogg        le fichier sur Wikimedia Commons, sans « File: »
#   titre: Le *Dies irae*         ce qu'on lit à côté du bouton (*italique* permise)
#   credit: …                     l'interprète, la date — la licence s'ajoute seule
#   pour: apocalypse              les articles où il s'écoute
#   extrait: 0 90                 (facultatif) le passage gardé, en secondes ; « 30 fin »
#   debit: 64 mono                (facultatif) le débit du MP3 réencodé, en kbit/s, et
#                                 « mono » pour un enregistrement qui l'est : 96 en stéréo
#                                 par défaut ; en mono à 64 ou moins, on passe à 22 050 Hz
#
# « % un titre » ouvre un lot : un « debit: » écrit juste après vaut pour tous
# les sons suivants, jusqu'au prochain « % ». Les 78 tours, les cylindres et les
# lectures sont en mono : ils n'ont rien à perdre à être compressés comme tels.
