# Les parcours : des chemins guidés à travers le dictionnaire, d'un article à
# l'autre, dans un ordre qui raconte une histoire.
#
#     node build/construire.mjs      les vérifie et les range dans le dictionnaire
#
# ── Un parcours ─────────────────────────────────────────────────────────────
#
#   = temple                      identifiant (minuscules, chiffres, tirets)
#   nom: Le Temple de Salomon     ce qu'on lit sur la carte du parcours
#   def: Une phrase.              ce que le parcours raconte
#   etapes: salomon, …            les articles, dans l'ordre (quatre au moins) ;
#     une ligne qui commence par deux espaces continue la liste
#
# Dans la fiche d'un article, le parcours qu'on suit montre l'étape, la
# précédente et la suivante ; l'accueil présente tous les parcours.
