# Les illustrations de l'application, et d'où elles viennent.
#
#     python build/illustrer.py      télécharge, vérifie la licence, convertit en WebP
#                                    dans img/ et écrit build/illustrations.json
#     node build/construire.mjs      rattache ensuite chaque image à ses articles
#
# Toutes viennent de Wikimedia Commons et sont dans le domaine public (ou sous
# CC0) : le script refuse toute autre licence. Ce sont des reproductions fidèles
# d'œuvres anciennes, que leur numérisation ne fait pas sortir du domaine public.
#
# ── Une image ───────────────────────────────────────────────────────────────
#
#   = conver-01                   identifiant : le fichier sera img/conver-01.webp
#   commons: Fichier.jpg          le fichier sur Wikimedia Commons, sans « File: »
#   legende: Le Bateleur          ce qu'on lit sous l'image (*italique* permise)
#   credit: BnF                   l'auteur, la date, le fonds — la licence s'ajoute seule
#   pour: arcane-bateleur         les articles où elle paraît, en tête de fiche
#   largeur: 440                  (facultatif) largeur en pixels, 400 par défaut
#   recadrer: 0.02 0 0.98 1       (facultatif) gauche haut droite bas, en fractions
#   page: 7                       (facultatif) la page d'un livre numérisé (PDF, DjVu)
#   teinter: #rrggbb ellipse …    (facultatif, plusieurs fois) colorie la gravure à la main :
#                                 une couleur pour toute l'image, puis des taches (ellipse cx cy rx ry,
#                                 rect x y l h, polygone x y, x y…), fondues et multipliées
#   detourer: x y, x y, …         (facultatif) ne garde que ce polygone, le reste transparent
#   clair: 0.75                   (facultatif, avec detourer) efface aussi ce qui est plus clair
#
# « % un titre » ouvre un lot : les champs écrits juste après valent pour toutes
# les images suivantes, jusqu'au prochain « % ».
#
# ── Une planche ─────────────────────────────────────────────────────────────
#
#   + arcanes-majeurs             l'article qui montre la planche
#   titre: Les vingt-deux…        sa légende
#   images: conver-01, conver-02  les vignettes, dans l'ordre ; chacune ouvre le
#                                 premier article de son « pour: », ou s'agrandit
