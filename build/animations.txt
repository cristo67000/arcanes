# Les images animées : ce qui se passe par-dessus certaines gravures.
#
#     node build/construire.mjs      vérifie chaque effet et le rattache à son image
#     js/animations.js               les dessine, quand l'image paraît à l'écran
#
# Une image (son identifiant dans build/illustrations.txt), puis ses lignes :
#
#   = portrait-lenormand
#   titre: L’as de cœur           le libellé du bouton « Rejouer » sous l'image
#   son: synth:carte              (facultatif) un bruit fabriqué sur place (carte,
#                                 coups, tonnerre, vent, feu, cloche, gong, tic, coeur,
#                                 enchantement, souffle, eau) ou un son de build/sons.txt
#   effet: carte; coins=…; …      un effet par ligne : son nom, puis ses réglages
#
# Les coordonnées sont des fractions de la largeur (x) et de la hauteur (y) de
# l'image, de 0 à 1 ; un point s'écrit « x y », une liste « x y, x y, … ».
#
#   carte       une carte à jouer posée par trois coins : coins=origine, haut, droite ;
#               figure=as-coeur | as-carreau | as-pique | as-trefle
#   teinte      une tache de couleur fondue dans la gravure (mode produit) :
#               ellipse=cx cy rx ry | rect=x y l h | polygone=… | rien (toute l'image) ;
#               couleur=#rrggbb ; force=0.55 ; flou=0.02 (fraction de la largeur)
#   bouge       un morceau de l'image découpé par un polygone : polygone=… ; pivot=x y ;
#               mode=tourne | balance | leve | tremble | flotte ; ampleur (degrés pour
#               tourne et balance, fraction de la hauteur sinon) ; duree (s) ; fois
#   lueur       une lumière : point=x y ; rayon (fraction de la largeur) ; couleur ;
#               mode=vacille | pulse | eclat ; force
#   etincelles  des étoiles qui scintillent : zone=x y l h ; nombre ; couleur ; taille
#   fumee       une fumée qui monte : point=x y ; couleur ; hauteur ; largeur ; nombre
#   eclair      l'image s'illumine ; trace=… (facultatif) le trait de l'éclair
#   rayons      une gloire qui tourne : point=x y ; rayon ; nombre ; couleur
#
# Tous acceptent delai=… (secondes avant de commencer).
